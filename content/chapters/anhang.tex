\section{Anhang}
\label{Anhang}
\subsection{Datenstrukturen}

\paragraph{Board (Hauptdatenstruktur)}\mbox{}\\
\label{Board}
\texttt{Board = \{board, Matrix, CurrentPlayer, Score\}} 
\begin{itemize}
	\item \texttt{Matrix}: Liste von 7 Spalten (Spaltenweise Organisation aufgrund der Spielmechanik.)
	\item \texttt{CurrentPlayer}: \texttt{\{Color, Count\}} mit \texttt{Color} $\in$ \{\texttt{red}, \texttt{blue}\}, \texttt{Count} $\geq$ 0
	\item \texttt{Score}: \texttt{running} $|$ \texttt{red} $|$ \texttt{blue} $|$ \texttt{remis}
\end{itemize}

\subparagraph{Spalte}\mbox{}\\
\texttt{Column = [Cell\textsubscript{1}, Cell\textsubscript{2}, ..., Cell\textsubscript{6}]}
\begin{itemize}
	\item Liste von 6 Zellen (von unten nach oben)
	\item \texttt{Cell}: \texttt{empty} $|$ \texttt{\{Color, Count\}}
\end{itemize}

\subparagraph{Koordinatensystem}
\begin{itemize}
	\item Links unten: (1,1), Rechts oben: (7,6)
	\item Spalten: 1--7 (horizontal), Reihen: 1--6 (vertikal)
\end{itemize}

\subsubsection{Wichtigsten Funktionen}

\paragraph{new\_board/0 $\rightarrow$ Board [E1] \label{E1}}\mbox{}\\
Initialisiert das Spiel und bedarf daher einer Näheren Betrachtung.
\begin{itemize}
	\item Erzeuge 7 leere Spalten mit je 6 Zellen (\texttt{empty})
	\item Setze \texttt{\{red, 0\}} als Startspieler, \texttt{Score = running}
\end{itemize}

\paragraph{make\_move/2 (Board, ColIdx) $\rightarrow$ Board $|$ Error [E2] \label{E2}}\mbox{}\\
Stellt die Kernfunktionalität dar, führt Spielzüge aus und aktualisiert den Zustand.
\begin{enumerate}
	\item Prüfe: \texttt{Score = running}? $\rightarrow$ sonst \texttt{\{error, \{game\_over, Score\}\}}
	\item Prüfe: $1 \leq \texttt{ColIdx} \leq 7$ $\rightarrow$ sonst \texttt{\{error, column\_outofrange\}}
	\item Finde erste leere Zelle in Spalte \texttt{ColIdx} (von unten)
	\begin{itemize}
		\item Falls keine: \texttt{\{error, column\_full\}}
	\end{itemize}
	\item Setze Chip \texttt{\{CurrentPlayer\}} in gefundene Zelle
	\item Berechne neuen \texttt{Score} via \texttt{score/1}
	\item Berechne \texttt{NextPlayer = \{andere Farbe, Count+1\}}
	\item Gebe \texttt{\{board, NewMatrix, NextPlayer, NewScore\}} zurück
\end{enumerate}

\paragraph{score/1 (Board) $\rightarrow$ Status [E3] \label{E3}}\mbox{}\\
Diese Funktion berechnet welcher Spieler Gewonnen bzw. verloren hat und ist damit essentiell.
\begin{enumerate}
	\item Prüfe \texttt{winner\_check(Matrix, red)} $\rightarrow$ \texttt{true}: \texttt{red}
	\item Sonst prüfe \texttt{winner\_check(Matrix, blue)} $\rightarrow$ \texttt{true}: \texttt{blue}
	\item Sonst prüfe \texttt{is\_full(Matrix)} $\rightarrow$ \texttt{true}: \texttt{remis}
	\item Sonst: \texttt{running}
\end{enumerate}

\paragraph{winner\_check(Matrix, Color) $\rightarrow$ Boolean [E3.1] \label{E3.1}}\mbox{}\\
Eine sehr wichtige Hilfsfunktion für score/1 und prüft ob 4 Steine nebeneinander liegen in allen Richtungen:
\begin{itemize}
	\item Horizontal: Iteriere über Reihen
	\item Vertikal: Iteriere über Spalten
	\item Diagonal $\searrow$: Alle Diagonalen von links-oben nach rechts-unten
	\item Diagonal $\nearrow$: Alle Diagonalen von links-unten nach rechts-oben
\end{itemize}

\paragraph{score\_ChipsRow/2 (Board, Player) $\rightarrow$ NumberList [E4] \label{E4}}\mbox{}\\
Wie in der Schnittstelle beschrieben, wird hier berechnet, wie viele gleichfarbige Chips um das nächste Freie Feld herum liegen. Die Vorgehensweise:

Für jede Spalte $i$ (1..7):
\begin{enumerate}
	\item Falls Spalte voll: $-1$ (Somit ist die nicht Spielbar)
	\item Sonst: Bestimme Position (ReihenIndex, $i$) des nächsten freien Feldes
	\item Zähle in alle 8 Richtungen gleichfarbige Chips:
	\begin{itemize}
		\item Links, Rechts, Oben, Unten, 4 Diagonalrichtungen
	\end{itemize}
	\item Summiere alle Nachbarschaften $\rightarrow$ [\texttt{Count\textsubscript{1}}, ..., \texttt{Count\textsubscript{7}}]
\end{enumerate}

\paragraph{check\_geq\_three/2 (Board, Player) $\rightarrow$ NumberList [E5] \label{E5}}\mbox{}\\
Überprüft in welchen Spaltennummern sich drei Chips (diagonal, horizontal oder vertikal) des Spielers zum freien Feld angrenzen.
\begin{itemize}
	\item Nutze \texttt{score\_ChipsRow/2} zur Berechnung
	\item Filter Spalten mit \texttt{Count} $\geq$ 3 $\rightarrow$ [\texttt{ColIdx\textsubscript{1}}, \texttt{ColIdx\textsubscript{2}}, ...]
\end{itemize}
